# 90-Second Demo Script

## Opening

"This is a working lead-response automation concept for HVAC and other service businesses. It captures a request, explains its urgency, assigns the right owner and schedules the next follow-up."

## Scenario 1: urgent repair

1. Select **Emergency**.
2. Point out the no-heat and baby-in-the-house signals.
3. Run the automation.
4. Show the urgent priority, Emergency Dispatch owner and five-minute callback action.
5. Emphasize that the notification is simulated in the portfolio demo.

## Scenario 2: installation quote

1. Select **Quote**.
2. Run the automation.
3. Show the normal priority, Comfort Advisor owner and quote follow-up.

## Close

"The demo uses FastAPI, SQLite and an importable n8n workflow. The same service boundaries can connect to a production CRM and messaging provider."

## Recording checklist

- Keep fictional contact data visible.
- Include the transparent-demo notice in the frame.
- Show one result and the updated pipeline.
- End with the architecture section.
- Avoid claiming client outcomes or production deployment.
